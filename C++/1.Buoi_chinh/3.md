## 1. Khái quát về hàm
Phần lớn các chương trình máy tính được xây dựng để giải quyết các bài toán lớn trong thực tế.
Cách tốt nhất để xây dựng và bảo trì một chương trình đó là xây dựng nó từ những thành phần nhỏ được xây dựng đơn lẻ. Chức năng Hàm (Function) được sử dụng để chia nhỏ chương trình thành các thủ tục nhỏ giải quyết từng chức năng nhỏ.

**Lợi ích của việc chia chương trình thành các hàm nhỏ:**
*   Code trở nên mạch lạc, dễ đọc.
*   Dễ debug khi gặp lỗi.
*   Có khả năng tái sử dụng lại code.
*   Dễ bảo trì khi cần thay đổi một chức năng nhỏ.

## 2. Cú pháp (Syntax)

```cpp
returntype functionName (parameter1, parameter2,...){
    //Function body
}
```

**TRONG ĐÓ:**
*   `returntype`: Kiểu trả về của hàm (int, double, bool, void,...)
*   `functionName`: Tên hàm
*   `parameter`: Tham số của hàm
*   `function body`: Các câu lệnh bên trong của hàm


```cpp
#include <iostream>
using namespace std;

    // kiểu trả về Ten ham(Danh sách tham số){
    //     // code 
    // }

    // viết hàm trả về dòng chữ hello

    // 1 hàm không cần trả về gì cả tức là thực hiện xong không trả về gì cả thì các bạn để kiểu dữ liệu là void
    void xinchao(){
        cout << "xin chao" << endl;
    }
    int main(){
    // c++ là hướng thủ tục và hướng đối tượng
    // c là ngôn ngữ hướng thủ tục
    xinchao(); // để chạy thì cần gọi hàm đó trong hàm main function call: lời gọi hàm
    xinchao(); // hàm có thể gọi nhiều lần
}

```
**Ví dụ:**
```cpp
void xinchao (){
    cout << "Hello 28tech!";
}
```
*Giải thích:*
*   Kiểu trả về `void`, tức hàm này không trả về giá trị nào.
*   `xinchao`: Tên hàm.
*   Hàm này không có tham số `()`.

## 4. Khai báo nguyên mẫu hàm (Function Prototype)
Các bạn có thể khai báo nguyên mẫu hàm ở đầu chương trình để làm cho chương trình rõ ràng hơn cũng như thông báo những hàm sẽ được sử dụng.

```cpp
// Function prototype
int max_val(int, int);

// Function declaration
int max_val(int a, int b){
    if (a > b)
        return a;
    else
        return b;
}
```

## 5. Tham số và Giá trị trả về (Parameter and Return Type)
Tham số là những giá trị được truyền cho hàm khi hàm được gọi.

**Ví dụ 1:**
```cpp
void printNumber(int a){
    cout << a << endl;
}

int main(){
    int n = 10;
    printNumber(n);
}
```
*Giải thích cách hoạt động:* Khi bạn gọi hàm `printNumber(n)` thì `n` được gọi là đối số hay tham số thực sự, còn `a` trong hàm là tham số hình thức. Giá trị của `n` sẽ được gán cho `a`, vì thế `a` cũng sẽ có giá trị là 10, và khi câu lệnh bên trong hàm printNumber thực hiện màn hình sẽ hiển thị giá trị `10`.

**Ví dụ 2:** Hàm nhận vào 3 số và trả về tổng của 3 số
```cpp
int tong(int a, int b, int c){
    return a + b + c;
}

int main(){
    int x = 100, y = 200, z = 300;
    cout << tong(x, y, z) << endl; 
    // OUTPUT: 600
}
```

## 6. Truyền tham chiếu và Truyền tham trị

### Truyền tham trị (Pass by value)
Khi bạn xây dựng hàm với cách truyền tham trị thì giá trị của tham số thực sự (`n`) được gán cho tham số hình thức (`a`), và những thay đổi bên trong hàm đối với tham số hình thức `a` sẽ không ảnh hưởng tới tham số thực sự.
```cpp
void add(int a){
    a += 100;
}

int main(){
    int n = 10;
    add(n);
    cout << n << endl; // OUTPUT: 10
}
```

### Truyền tham chiếu (Pass by reference)
Ngược lại nếu bạn truyền tham chiếu thì những gì bạn thay đổi trong tham số hình thức sẽ làm tham số thực sự bị thay đổi theo.
*Chú ý: Nếu bạn muốn thay đổi của một tham số sau khi hàm được thực hiện xong, hãy truyền tham chiếu, ngược lại bạn hãy truyền tham trị.*
```cpp
void add(int &a){
    a += 100;
}

int main(){
    int n = 10;
    add(n);
    cout << n << endl; // OUTPUT: 110
}
```

## 8. Nạp chồng hàm (Function Overloading)
Nạp chồng hàm là một tính năng của C++ khi mà các hàm có cùng tên nhưng khác nhau về tham số, kiểu trả về. Khi hàm được gọi thì tùy vào kiểu dữ liệu của tham số, hàm phù hợp sẽ được gọi.

```cpp
int findMax(int a, int b){
    if(a > b) return a;
    else return b;
}

float findMax(float a, float b){
    if(a > b) return a;
    else return b;
}

int main(){
    int x = 100, y = 200;
    cout << findMax(x, y) << endl;
    
    float m = 100.5, n = 200.5;
    cout << findMax(m, n) << endl;
}
```

## 9. Các hàm toán học phổ biến trong C++
Các bạn sử dụng thư viện `#include <bits/stdc++.h>` để thêm mọi thư viện của C++ vào chương trình, tránh phải khai báo từng thư viện riêng lẻ.

| Hàm | Chức năng | Ví dụ |
| :--- | :--- | :--- |
| `max` | Tìm giá trị lớn nhất | `cout << max(10, 20); // 20`<br>`cout << max({10, 20, 30, 40}); // 40` |
| `min` | Tìm giá trị nhỏ nhất | `cout << min(10, 20); // 10`<br>`cout << min({10, 20, 30, 40}); // 10` |
| `sqrt(n)` | Hàm tính căn bậc 2 của n, trả về số double | `int n = 100;`<br>`int can = sqrt(n); // can = 10.000 = 10` |
| `pow(x,y)` | Hàm tính $x^y$, trả về số double | `int x = 2, y = 10;`<br>`int res = pow(x, y); // res = 1024.000 = 1024` |
| `ceil(n)` | Hàm trả về số nguyên lớn hơn gần nhất với n | `float a = 2.3;`<br>`int res = ceil(a); // res = 3.000 = 3` |
| `floor(n)`| Hàm trả về số nguyên nhỏ hơn gần nhất với n | `float a = 2.3;`<br>`int res = floor(a); // res = 2.000 = 2` |
| `round(n)`| Làm tròn n tùy thuộc vào phần thập phân | `float a = 2.3; float b = 2.5;`<br>`int res1 = round(a); // 2.000 = 2`<br>`int res2 = round(b); // 3.000 = 3` |
| `abs(n)` | Trả về trị tuyệt đối của n | `cout << abs(-100); // 100` |
