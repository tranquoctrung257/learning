## 1. Khuôn mẫu chung của một chương trình C++
### Chương trình C++ đầu tiên

```cpp
#include <iostream>  // Khai báo thư viện cần thiết
using namespace std; // Thêm namespace

// Hàm main: là nơi bắt đầu thực thi của chương trình
int main () {
    cout << "Hello world!" << endl;
    return 0;
}
```

**Những phần chính của một chương trình C++:**
1. Thư viện mà chương trình sử dụng.
2. Namespace.
3. Chương trình chính với mã nguồn.

### Những chú ý khi viết chương trình C++
*   **Các câu lệnh kết thúc bằng dấu `;`**
    *   *Không hợp lệ:* `cout << "Hello 28tech" <<`
    *   *Hợp lệ:* `cout << "Hello 28tech" << ;` (Thực tế lệnh đúng là `cout << "Hello 28tech";`)
*   **Luôn thụt lề các câu lệnh so với hàm main** để code dễ đọc hơn.

## 2. Kiểu dữ liệu (Data Type)

### Kiểu dữ liệu số nguyên ($1 \text{ byte} = 8 \text{ bit}$)
Đối với số nguyên ta chia làm số nguyên không dấu và số nguyên có dấu. Từ số byte lưu trữ ta có thể suy ra số bit cần để biểu diễn số nguyên đó, quy tắc xác định giá trị của 1 số nguyên:
Giả sử số nguyên có $K$ bit:
*   **Số nguyên có dấu:** $-2^{K-1}$ tới $2^{K-1}-1$
*   **Số nguyên không dấu:** $0$ tới $2^{K}-1$

| Kiểu dữ liệu | Ý nghĩa | Số Byte | Dải giá trị có thể lưu |
| :--- | :--- | :--- | :--- |
| `short` | Số nguyên có dấu | 2 byte | -32768 đến 32767 |
| `unsigned short` | Số nguyên không dấu | 2 byte | 0 đến 65535 |
| `int` | Số nguyên có dấu | 4 byte | -2147483648 đến 2147483647 [-2.10^9 --> 2.10^9] |
| `unsigned int` | Số nguyên không dấu | 4 byte | 0 đến 4294967295 |
| `long long` | Số nguyên | 8 byte | -9223372036854775808 đến 9223372036854775807  [-9.10^18 --> 9.10^18]  |
| `unsigned long long`| Số nguyên không dấu | 8 byte | 0 đến $2^{64} -1$ |

### Kiểu dữ liệu số thực

| Kiểu dữ liệu | Ý nghĩa | Số Byte | Dải giá trị có thể lưu |
| :--- | :--- | :--- | :--- |
| `float` | Số thực độ chính xác đơn | 4 byte | Độ chính xác: 7 chữ số sau dấu phẩy |
| `double` | Số thực độ chính xác kép | 8 byte | Độ chính xác: 15 chữ số sau dấu phẩy |
*(Ưu tiên sử dụng `double` vì `double` có độ chính xác cao hơn `float`)*

### Kiểu dữ liệu đúng/sai (Boolean)

| Kiểu dữ liệu | Ý nghĩa | Số Byte | Dải giá trị có thể lưu |
| :--- | :--- | :--- | :--- |
| `bool` | Kiểu dữ liệu luận lý | 1 byte | `true` (Đúng) hoặc `false` (Sai) |

### Kiểu dữ liệu ký tự

| Kiểu dữ liệu | Ý nghĩa | Số Byte | Dải giá trị có thể lưu |
| :--- | :--- | :--- | :--- |
| `char` | Kiểu dữ liệu ký tự | 1 byte | -128 tới 127 |

### Tổng quan về kiểu dữ liệu:
1.  **Kiểu số nguyên:** có `int` và `long long`. (Sử dụng `long long` cho các kết quả là số lớn).
2.  **Kiểu số thực:** có `float` và `double`. (Sử dụng `double` vì có độ chính xác cao).
3.  **Kiểu đúng sai:** có `bool`.
4.  **Kiểu ký tự:** có `char`.

## 3. Biến (Variable)

**Khái niệm:** Biến được sử dụng để lưu các giá trị trong quá trình tính toán của chương trình. Tùy theo kiểu dữ liệu của biến, một ô trong bộ nhớ sẽ được cấp phát để lưu trữ giá trị của biến này.

**Cú pháp:**
`[Kiểu dữ liệu] [Tên biến];`
*(Ví dụ: `int x;`, `long long b;`, `char ki_tu;`, `bool check;`, `double dienTich;`)*

**Quy tắc đặt tên biến:**
1. Không đặt tên biến bắt đầu bằng số. *(Lỗi: `1dientich`, `2chuvi`)*
2. Tên biến không được chứa dấu cách và các kí tự đặc biệt. *(Lỗi: `ban kinh`, `dien#tich`)*
3. Tên biến không được trùng với từ khóa trong C++. *(Lỗi: `int`, `main`, `for`, `while`)*
4. Tên biến trong C++ là phân biệt hoa thường. *(`banKinh` và `BanKinh` là 2 biến khác nhau)*
5. Không được đặt 2 biến có cùng tên trong cùng một phạm vi. *(Lỗi: `int a; float a;`)*

## 4. Chú thích (Comment)

**Khái niệm:** Chú thích (Comment) là một giải pháp bổ sung thông tin vào code nhằm làm rõ nội dung, giải thích câu lệnh, mục đích của code... Giúp người đọc dễ nắm bắt nội dung và bảo trì code. Các chú thích sẽ bị loại bỏ khi chương trình thực thi.

**Cách chú thích:**
*   Để chú thích trên 1 dòng ta dùng `//`
    ```cpp
    // Đây là chú thích
    // Chú thích giúp code rõ ràng hơn
    ```
*   Để chú thích trên nhiều dòng ta dùng `/* Nội dung */`
    ```cpp
    /*
    Đây là
    chú thích trên nhiều dòng
    */
    ```

## 6. Toán tử (Operator)

### Toán tử gán (Assignment Operator)
**Cú pháp:** `[Toán hạng 1] = [Toán hạng 2]`
**Ý nghĩa:** Gán giá trị của toán hạng 2 cho toán hạng 1.
```cpp
ban_kinh = 100; // Gán giá trị 100 cho biến ban_kinh
Chu_vi = 1000;  // Gán giá trị 1000 cho biến Chu_vi
```

### Toán tử toán học (Arithmetic Operator)
| Toán tử | Ý nghĩa | Ví dụ |
| :---: | :--- | :--- |
| `+` | Cộng 2 toán hạng | `X = 100 + 200;` // 300 |
| `-` | Trừ 2 toán hạng | `X = 200 - 100;` // 100 |
| `*` | Nhân 2 toán hạng | `X = 10 * 50;` // 500 |
| `/` | Chia 2 toán hạng | `X = 300 / 200;` // 1 (Chia nguyên) |
| `%` | Chia dư 2 toán hạng| `X = 300 % 200;` // 100 |

```cpp
#include <iostream>

using namespace std;

int main(){
    // trong khi chương trình chạy ta có thể thay đổi được biến n
    int n = 100;
    n = 200;
    n = 300;
    cout << n << endl;

    // các phép toán trong c++ + - * / % chia lấy dư
    // ví dụ cho 2 biến tính tổng hiệu tích thương
    int a = 300, b = 200;
    cout << a + b << endl;
    cout << a - b << endl;
    cout << a * b << endl;
    cout << a / b << endl;
    cout << a % b << endl;
    // lưu ý: khi chia 2 số nguyên int long long cho nhau sẽ ra số nguyên 
    // còn khi chia 1 trong 2 số là số thực thì sẽ ra số thực có thể ép kiểu 1 trong 2 số chia hoặc số bị chia| có cách khác nữa là nhân với 1.0
    double thuong = (double)a/b;
    cout << thuong  << endl;
    // để ép kiểu (data type) tên biến -> ép biến tên biến thành kiểu dữ liệu data type
}
```


**Chú ý 1 (Phép chia):** Nếu chia 2 số nguyên cho nhau, kết quả chỉ lấy phần nguyên. Muốn kết quả là số thập phân thì ít nhất 1 trong 2 số phải ép sang kiểu số thực.
```cpp
int a = 100, b = 30;
// Cách 1: Ép kiểu
float thuong1 = (float) a / b; 
// Cách 2: Nhân thêm số thực
float thuong2 = 1.0 * a / b; 
```

**Chú ý 2 (Tràn số):** Nếu nhân 2 số `int` vượt giới hạn thì sẽ bị tràn, dù gán vào biến `long long`. Cần can thiệp vào phép nhân.
```cpp
int a = 1000000, b = 1000000;
// Sai:
long long tich = a * b; // tràn số
// Đúng:
long long tich = (long long) a * b;
long long tich = 1ll * a * b; // '1ll' là số 1 kiểu long long
```

```cpp
#include <iostream>

using namespace std;

int main(){
    int m = 100000;
    int n = 100000;
    // int tich = m * n; sẽ ra số sai vì đã bị tràn số, 1 trong 2 số phải là long long
    // int * int => kq lưu tạm vào bộ nhớ 4 byte 
    // long long tich = (long long)m * n;
    long long tich = 1LL * m * n; // 1 ll là 1 long long
    // ==> khi nhân 2 số int mà vượt ngưỡng kết quả int => ép kiểu trước khi nhân
    cout << tich << endl;
}
```

### Toán tử so sánh (Comparison Operator)
| Toán tử | Ý nghĩa | Ví dụ |
| :---: | :--- | :--- |
| `>` | Lớn hơn | `10 > 50` (false) |
| `>=` | Lớn hơn hoặc bằng | `20 >= 10` (true) |
| `<` | Nhỏ hơn | `10 < 50` (true) |
| `<=` | Nhỏ hơn hoặc bằng | `20 <= 20` (true) |
| `!=` | So sánh khác | `10 != 20` (true) |
| `==` | So sánh bằng | `10 == 10` (true) |

### Toán tử logic (Logical Operator)
| Toán tử | Ký hiệu | Ví dụ | Ý nghĩa |
| :--- | :---: | :--- | :--- |
| **AND** | `&&` | `(x >= 10) && (x <= 50)` | Chỉ ĐÚNG khi mọi mệnh đề thành phần đều ĐÚNG. |
| **OR** | `\|\|` | `(a >= 10) \|\| (a % 2 == 0)` | Chỉ SAI khi mọi mệnh đề thành phần đều SAI. |
| **NOT** | `!` | `!(a <= 10)` | Phủ định kết quả mệnh đề. |

### Toán tử tăng giảm (Increment, Decrement)
| Toán tử | Ý nghĩa | Ví dụ |
| :---: | :--- | :--- |
| `++` (trước)| Tăng trước 1 đơn vị | `++a` (Tăng `a` lên 1 rồi mới gán/thực thi) |
| `++` (sau) | Tăng sau 1 đơn vị | `a++` (Gán/thực thi trước rồi mới tăng `a` lên 1) |
| `--` (trước)| Giảm trước 1 đơn vị | `--a` |
| `--` (sau) | Giảm sau 1 đơn vị | `a--` |

### Toán tử 3 ngôi (Conditional Operator)
**Cú pháp:** `[Biểu thức so sánh] ? [Giá trị trả về khi đúng] : [Giá trị trả về khi sai]`
```cpp
int x = (10 < 20) ? 10 : 20; // x = 10
int y = ((10 < 20) && (20 > 20)) ? 5 : 10; // y = 10
```

```cpp
#include <bits/stdc++.h>
#include <math.h>
using namespace std;

int main(){
    // toán tử 3 ngôi
    int a = 100, b = 200;
    int max1;
    // đk ? true : false 
    max1 = a > b ? a : b;
    cout << max1 << endl;

}
```

> **GHI CHÚ:** Dấu đóng mở ngoặc tròn `()` luôn có độ ưu tiên cao nhất, nên sử dụng ngoặc để biểu thức thực thi đúng mong muốn.

## 7. Cấu trúc rẽ nhánh

### 1. Câu lệnh IF
Thực hiện 1 nhóm câu lệnh khi điều kiện thỏa mãn.
```cpp
if (condition) {
    // code
}
```
*Ví dụ:*
```cpp
int a = 100, b = 200;
if (a < b) {
    cout << "OK"; // In ra OK vì 100 < 200 là đúng
}
```

### 2. Câu lệnh IF ... ELSE
Thực thi nhánh `if` nếu điều kiện đúng, nhánh `else` nếu điều kiện sai.
```cpp
if (condition) {
    // code if
} else {
    // code else
}
```
*Ví dụ:*
```cpp
int a = 100;
if ((a % 2) == 0) {
    cout << "Chan";
} else {
    cout << "Le";
}
```

```cpp
#include <iostream>

using namespace std;

int main(){
    //Ví dụ kiểm tra n >= 500 và nhỏ hơn <= 1000
    int n = 100;
    if(n<20){
        cout << "n bé hơn 20" << endl;
    }
    else{
        cout << "n lớn hơn 20" << endl;
    }

}
```


### 3. Câu lệnh IF ... ELSE IF
Kiểm tra nhiều điều kiện. Nếu một điều kiện đúng, nhánh đó thực thi và thoát khỏi toàn bộ khối rẽ nhánh.
```cpp
if (condition1) {
    // code
} else if (condition2) {
    // code
} else if (conditionN) {
    // code
} else {
    // code
}
```
> mức độ ưu tiên của condition sẽ giống như trong đại số nhân chia trước cộng trừ sau và thực hiện từ trái qua phải ở các toán tử có cùng độ ưu tiên, nhưng lưu ý toán tử nào cần thực hiện trước thì đưa vào trong ngoặc.
### 4. Câu lệnh SWITCH CASE
So sánh giá trị biến với lần lượt các case. Dùng cho kiểm tra giá trị cụ thể (số, ký tự).
```cpp
switch (val) {
    case 1:
        // code
        break;
    case 2:
        // code
        break;
    default:
        // code (thực thi khi không có case nào khớp)
}
```

```cpp
#include <iostream>

using namespace std;

        cout << "Thu hai !\n";
    }
    else if (n == 3) {
        cout << "Thu ba !\n";
    }
    else if (n == 4) {
        cout << "Thu tu !\n";
    }
    else if (n == 5) {
        cout << "Thu nam !\n";
    }

        cout << "Thu sau !\n";
    }
    else if (n == 7) {
        cout << "Thu bay !\n";
    }

    }
```

## 8. Bảng mã ASCII và các lệnh liên quan

Kiểu `char` có thể coi là số nguyên (mã ASCII), có thể dùng để cộng, trừ, nhân, chia.
**Một vài dải kí tự cần lưu ý:**
*   `A - Z` : Mã từ `65 - 90`
*   `a - z` : Mã từ `97 - 122`
*   `0 - 9` : Mã từ `48 - 57`

| `if ((c >= '0') && (c <= '9'))` hoặc `if ((c >= 48) && (c <= 57))`| Kiểm tra kí tự là chữ số |
| `c += 32;` | Chuyển kí tự in hoa thành in thường (VD: 'A' + 32 = 'a') |
