# Tìm hiểu sơ bộ về ngôn ngữ c++

## 1.Chương trình C++ đầu tiên

```c++
#include <iostream>
using namespace std;

int main(){
    // tất cả code sẽ được viết ở đây
    cout << "Hello World!";// câu lệnh in ra dòng chữ Hello World!
}
```

`#include <iostream>`viết tắt của input output stream: chứa các hàm đọc ghi.


## 2. kiểu dữ liệu trong C++.

Kiểu dữ liệu số nguyên: 
- `int` 4 byte ~ 32bit | giá trị từ -2^31 đến 2^31 -1 [-2.10^9 --> 2.10^9]
- `long long` 8 byte ~ 64 bit | giá trị từ -2^63 đến 2^63 -1 [-9.10^18 --> 9.10^18]  

>`Lưu ý:` int long long không lưu được số thực.

Kiểu dữ liệu số thực: 
- float: 4 byte ~ 32 bit. 6 số thập phân
- double: 8 byte ~ 64 bit. 15 số thập phân

Kiểu dữ liệu kí tự
- kí tự char: character: 1byte lưu các kí tự.

Để in ra kiểu giá trị min max của int

```c++
#include <iostream>
using namespace std;

int main(){
    cout << INT_MIN << " " << INT_MAX << endl;
}
```

```
-2147483648 
2147483647
```

Để in ra kiểu giá trị min max của long long 

```c++
#include <iostream>
using namespace std;

int main(){
    cout << LLONG_MIN << " " << LLONG_MAX << endl;
}
```
```
-9223372036854775808 
9223372036854775807
```
