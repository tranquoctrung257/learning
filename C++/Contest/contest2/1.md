## Bài 1. Tính tổng ước của số nguyên dương $n$. Độ phức tạp mong đợi $O(\log n)$

### Input Format

Số nguyên dương $N$

### Constraints

$1 \le N \le 10^{10}$

### Output Format

Tổng ước của $N$

### Sample Input 0

```
28
```

### Sample Output 0

```
56
```

## Đếm số lượng ước và liệt kê các ước theo thứ tự tăng dần của số nguyên dương $N$

### Input Format

Số nguyên dương $N$.

### Constraints

$1 \le N \le 10^6$

### Output Format

* Dòng đầu tiên in ra số lượng ước của $N$.
* Dòng thứ hai in ra các ước của $N$ theo thứ tự tăng dần, cách nhau bằng khoảng trắng.

### Sample Input 0

```
28
```

### Sample Output 0

```
6
1 2 4 7 14 28
```

## [Vòng lặp]. Bài 5

Nhập vào 1 dãy số có không quá 10000 số nguyên. Hãy xác định trong quá trình nhập có xuất hiện số 2022 hay không?

### Input Format

Dòng đầu tiên là số lượng số nguyên sẽ nhập: $N$. Dòng thứ 2 là $N$ số viết cách nhau một khoảng trắng.

### Constraints

$1 \le N \le 10000$; Các số được nhập là số nguyên không quá $10^6$.

### Output Format

In `YES` nếu trong các số vừa nhập có số 2022, ngược lại in `NO`.

### Sample Input 0

```
4
2019 2020 2021 2022
```

### Sample Output 0

```
YES
```

## \[Vòng lặp\]. Bài 7. Tổng bình phương

Tính tổng $S(n) = 1^2 + 2^2 + 3^2 + 4^2 + ... + n^2$.

Gợi ý : Tạo 1 biến kết quả gọi là `tong` và khởi tạo bằng $0$ (tránh giá trị rác), sau đó sinh ra 1 vòng lặp chạy từ $1$ tới $n$, mỗi vòng lặp thì giá trị $i * i$ với $i$ là biến của vòng lặp vào biến `tong`. In ra biến `tong` SAU KHI VÒNG LẶP KẾT THÚC

### Input Format

Số nguyên dương $n$.

### Constraints

$1 \le n \le 10^5$

### Output Format

$S(n)$

### Sample Input 0

```
3

```

### Sample Output 0

```
14
```

## [Vòng lặp]. Bài 8. Tổng bội của 3

Nhập vào giá trị của $n$ không quá $10^6$, tính tổng các số nguyên dương không vượt quá $n$, chia hết cho $3$.

**Gợi ý:** Tạo 1 biến kết quả gọi là `tong` và khởi tạo bằng $0$ (tránh giá trị rác), sau đó sinh ra 1 vòng lặp chạy từ $1$ tới $n$, mỗi vòng lặp thì kiểm tra xem $i$ chia hết cho $3$ thì cộng biến $i$ của vòng lặp vào biến `tong`. In ra biến `tong` SAU KHI VÒNG LẶP KẾT THÚ.

### Input Format

Số nguyên dương $n$

### Constraints

$1 \le n \le 10^6$

### Output Format

Kết quả của bài toán

### Sample Input 0

```
10
```

### Sample Output 0

```
18
```

## \[Vòng lặp\]. Bài 9. Tổng nghịch đảo

Tính tổng: $S = 1 + 1/2 + 1/3 + 1/4 + \dots + 1/n$.

**Gợi ý:** Tạo 1 biến kết quả gọi là `tong` và khởi tạo bằng $0$ (tránh giá trị rác), sau đó sinh ra 1 vòng lặp chạy từ $1$ tới $n$, mỗi vòng lặp thì cộng giá trị $1 / i$ của vòng lặp vào biến `tong`. In ra biến `tong` SAU KHI VÒNG LẶP KẾT THÚ.

### Input Format

Số nguyên dương $n$

### Constraints

$1 \le n \le 10^5$

### Output Format

In ra kết quả lấy độ chính xác $3$ số sau dấu phẩy.

### Sample Input 0

```
2
```

### Sample Output 0

```
1.500
```
