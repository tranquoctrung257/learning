# Làm quen cơ bản với Java

## 1. Kiểu dữ liệu (Data type) trong Java

`Java` sẽ có 2 kiểu dữ liệu chính là:
- Kiểu dữ liệu `nguyên thủy`. 
- kiểu dữ liệu tham chiếu.

> Nhưng bài hôm nay chúng ta sẽ cùng tìm hiểu sâu về kiểu dữ liệu `nguyên thủy` còn kiểu dữ liệu tham chiếu chúng ta sẽ nhắc tới nó vào những bài sau vì nó sẽ liên quan lập trình hướng đối tượng(OPP).

Kiểu dữ liệu nguyên thủy sẽ có các kiểu dữ liệu sau:

- Kiểu dữ liệu `số nguyên`:
    - `byte` 1byte ~ 8bit | khoảng giá trị từ -128 đến 127.
    - `short` 2byte ~ 16bit | khoảng giá trị từ -32768 đến 32767.
    - `int` 4byte ~ 32bit | khoảng giá trị từ -2^31 đến 2^31-1.
    - `long` 8byte ~ 64bit | khoảng giá trị từ -2^63 đến 2^63 từ -9.10^18 đến 9.10^18.
    - `byte` với `short` sẽ ít khi sử dụng vì kích thước khá nhỏ.
- Kiểu dữ liệu `số thực`:
    - `float` 4byte ~ 32bit |  độ chính xác khoảng 6 đến 7 số sau dấu phẩy.
    - `double` 8byte ~ 64bit | độ chính xác khoảng 15 chữ số sau dấu phẩy.
- Kiểu `kí tự`:
    - `char` 2byte lưu các ký tự char được viết trong dấu nháy đơn
    - Lưu ý: kí tự được viết trong dấu nháy đơn ' ' còn dấu nháy kép " " là chuỗi kí tự. Khi khai báo biểu dữ liệu char mà gán giá trị được khai báo bằng " " thì chương trình sẽ báo lỗi. 
- Kiểu `boolean`:
    - `boolean` 1byte chỉ lưu đúng 2 giá trị trị `true` `false`.

## 2.Biến (Variable).
> Định nghĩa: Giống các ngôn ngữ khác, biến là một vùng trên bộ nhớ dùng để lưu tạm một giá trị nào đó để chương trình thao tác. Giá trị của biến sẽ thay đổi nếu ta thực hiện các phép thay đổi trên nó

- cách đặt tên biến:`[kiểu dữ liệu] = [tên biến]`

ví dụ:
```java
int a;
long b;
double c;
float d;
char kitu;
```

Hoặc có thể khai báo nhiều kiểu dữ liệu trên cùng 1 dòng (nhưng bắt buộc phải chung kiểu dữ liệu).

```java
int a,b,c,d;
```

> **Lưu ý:** Trong Java chỉ khai báo biến đúng 1 lần, khai báo lần thứ 2 chương trình sẽ báo lỗi.

Một số ví dụ về khai báo biến.

```java
int a = 500;
// Khởi tạo biến a là kiểu dữ liệu int và gán giá trị biến a bằng 50
```
> **Lưu ý:** Trong Java sẽ có quy tắc đặt tên biến áp dụng cho lập trình viên toàn thế giới là quy tắc `convention`

Quy tắc sẽ như sau:
- Tên biến được chia thành các từ, ngoại trừ từ đầu tiên thì các từ sau phải viết hoa chữ cái đầu và viết thường chữ cái sau.
- Bạn có thể tham khảo bài viết. [Code convention là gì? Các quy tắc chung khi viết code](https://vietnix.vn/code-convention-la-gi/)

## 3. Chú thích (comment) trong Java.
> Định nghĩa: Chú thích là những dòng được tạo ra để ghi chú lại những lỡi giải thích của đoạn code nào đó hoặc chúng ta còn có thể comment đoạn code nào đó.

Có 2 kiểu comment trong Java là:
- Chú thích 1 dòng `//` .
- Chú thích nhiều dòng `/**/`.

```Java
// đây là chú thích 1 dòng
// int a;
```

```java
/*
còn đây là chú thích trên nhiều dòng.
int a;
int b;
char c;
*/
```

## 4. Chương trình đầu tiên Java

### In dữ liệu ra màn hình.
``` java
public class Main{
    public static void main(String[] args){
        int a = 500; // khai báo và khởi tạo biến a = 500
        System.out.println(a);
    }
}
```

> 500

Hiện tại bạn chưa cần qua tâm đến các dòng code trên vội mà chỉ cần quan tâm tới dòng `System.out.println(a);`

- Dòng này dùng để in ra màn hình giá trị của biến a.   
- println là in xong xuống dòng, print là in xong sẽ không xuống dòng.

### Nhập dữ liệu từ bàn phím.

```java
import java.util.Scanner;

public class Main{
    public static void main(String[] args){
        int n ;
        float c;
        char Kitu;
        Scanner sc = new Scanner(System.in);
        n = sc.nextInt(); // nhập dữ liệu theo kiểu int

        System.out.println(n);

        // hàm nhập số float 
		c = sc.nextFloat();
		System.out.println(c);

    	// để nhập 1 kí tự từ bàn phím
		char kiTu = sc.nextLine().charAt(0);
		System.out.println(kiTu);

		// để nhập nhiều số trên cùng 1 dòng
		int q = sc.nextInt(), w = sc.nextInt() , e = sc.nextInt();
		System.out.print(q + " " + w +  " " + e);
    }
}
```
> **Lưu ý:** nếu khai báo int mà nhập kiểu dữ liệu khác thì java sẽ báo là `java.util.InputMismatchException`.

1. \+ cộng
2. \- trừ
3. \* nhân 
4. \/ chia
5. \% chia lấy phần dư

> **Lưu ý:** phần chia, chia 2 số nguyên với nhau sẽ ra số nguyên mà muốn ra số thực thì ép 1 trong 2 số thành số thực.

```Java
public class Main{
    public static void main(String[] args){
		int m = 5;
		int = 2;
		double res = (float)m/n;
		System.out.printf("%.2f",res); // cách để in ra bao nhiêu số đằng sau dấu phẩy

```

1 số lỗi hay mắc phải ở nhân 2 số nguyên lớn.
```Java
public class Main{
    public static void main(String[] args){
		int p = 1000000000;
		int l = 1000000000;
		// long res = p * l; như thế này nó sẽ ra lỗi vì nếu lấy 2 số int nhân với nhau thì nó sẽ lấy tích thằng này lưu tạm vào vùng nhớ int sau đó với gán cho thằng res nên ở đây cũng sẽ bị tràn.
		// cách làm đúng sẽ là
		long res = (long)p * l;
		System.out.println(res);
    }

```
> 1000

Trong `java` là nhân chia trước cộng trừ sau nếu cùng độ ưu tiên thì sẽ từ bên phải qua | trong Java nếu muốn chính xác nhất thì mở ngoặc đóng ngoặc đầy đủ.

## 6.Toán tử so sách trong java.
> Toán tử so sánh sẽ trả về true hoặc false.
1. \> lớn hơn 
2. \< nhở hơn
3. \>= lớn hơn hoặc bằng
4. \<= nhỏ hơn hoặc bằng
5. \!= so sánh khác
6. \== so sánh bằng

ví dụ:

```java
public class Main{
    public static void main(String[] args){
		int p = 1000000000;
		int l = 1000000000;
        System.out.println(p>l);
    }
}
```

> false

## 7. Một số hàm toán học có sẵn trong Java.
Hàm `trị tuyệt đối.`
```java
// hàm trị tuyệt đối 
public class Main{
    public static void main(String[] args){
        System.out.println(Math.abs(-100));
    }
}
```

Hàm `căn bậc 2`
```java
// hàm căn bậc 2 sqrt | trả lại số thực
public class Main{
    public static void main(String[] args){
        System.out.println(Math.sqrt(49));
    }
}
```
> 7.0

Hàm `lũy thừa`
```java
// pow tính lũy thừa trả về số thực
public class Main{
    public static void main(String[] args){
        System.out.println(Math.sqrt(49));
    }
}

```

Hàm `min` `max`
```java
// hàm max,min tìm số lớn nhất và nhỏ nhất trong 2 số
public class Main{
    public static void main(String[] args){
        System.out.println(Math.max(-221,3312));
		System.out.println(Math.min(-221,3312));
		System.out.println(Math.max(321,423));
    }
}
```
```
3312
-221
423
```

Hàm `mũ `
```java
public class Main{
    public static void main(String[] args){
        int luythua = (int)Math.pow(2,10); // ép kiểu math để tránh báo về mất mát dữ liệu
		System.out.println(luythua);
    }
}
```
>1024

Các hàm `làm tròn`.
```java
public class Main{
    public static void main(String[] args){
		double s = 3.323;
        // ceil làm tròn lên	
        System.out.println(Math.ceil(s));

		// floor làm tròn xuống  	
        System.out.println(Math.floor(s));

		// round làm tròn phụ thuộc vào phần thập phân
        System.out.println(Math.round(s));
    }
}
```
```
4.0
3.0
3
```
