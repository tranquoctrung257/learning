## 1. Kiểu dữ liệu và biến

`Java` sẽ có 2 kiểu dữ liệu chính là:
- Kiểu dữ liệu `nguyên thủy`. 
- kiểu dữ liệu tham chiếu.

> Nhưng bài hôm nay chúng ta sẽ cùng tìm hiểu sâu về kiểu dữ liệu `nguyên thủy` còn kiểu dữ liệu tham chiếu chúng ta sẽ nhắc tới nó vào những bài sau vì nó sẽ liên quan lập trình hướng đối tượng(OPP).

Kiểu dữ liệu nguyên thủy sẽ có các kiểu dữ liệu sau:

| Kiểu dữ liệu | Kích thước (byte) | Giá trị |
| :--- | :--- | :--- |
| `byte` | 1 byte | $-128$ đến $127$ |
| `short` | 2 byte | $-32768$ đến $32767$ |
| `int` | 4 byte | $-2^{31}$ đến $2^{31} - 1$ |
| `long` | 8 byte | $-2^{63}$ đến $2^{63} - 1$ |
| `float` | 4 byte | Lưu số thực độ chính xác từ 6 tới 7 chữ số sau dấu phẩy |
| `double` | 8 byte | Lưu số thực độ chính xác tới 15 chữ số sau dấu phẩy |
| `char` | 2 byte | Lưu các kí tự |
| `boolean` | 1 byte | Lưu giá trị `true` (đúng) hoặc `false` (sai) |

### b. Biến (Variable)
Biến được sử dụng để lưu các giá trị trong quá trình tính toán của chương trình. Tùy theo kiểu dữ liệu của biến, một ô trong bộ nhớ sẽ được cấp phát để lưu trữ giá trị của biến này.

#### Quy tắc đặt tên biến:
1. Không được đặt tên biến bắt đầu bằng chữ số (Ví dụ sai: `1dientich`, `2chuvi`, `222bankinh`,...).
2. Tên biến không được chứa dấu cách và các kí tự đặc biệt (Ví dụ sai: `ban kinh`, `dien#tich`, `chu@vi`,...).
3. Tên biến không được trùng với tên từ khóa trong Java (Ví dụ: `int`, `main`, `for`, `while`,...).
4. Tên biến trong Java là phân biệt hoa thường (Ví dụ: `banKinh` và `BanKinh` là khác nhau).

#### Cú pháp khai báo biến:
```java
[Kiểu dữ liệu] [Tên biến];
```

ví dụ:
```java
int a;
long b;
double c;
float d;
char kitu;
```

Hoặc có thể khai báo nhiều kiểu dữ liệu trên cùng 1 dòng (nhưng bắt buộc phải chung kiểu dữ liệu).

```java
int a,b,c,d;
```

> **Lưu ý:** Trong Java chỉ khai báo biến đúng 1 lần, khai báo lần thứ 2 chương trình sẽ báo lỗi.

Một số ví dụ về khai báo biến.

```java
int a = 500;
// Khởi tạo biến a là kiểu dữ liệu int và gán giá trị biến a bằng 50
```
> **Lưu ý:** Trong Java sẽ có quy tắc đặt tên biến áp dụng cho lập trình viên toàn thế giới là quy tắc `convention`

Quy tắc sẽ như sau:
- Tên biến được chia thành các từ, ngoại trừ từ đầu tiên thì các từ sau phải viết hoa chữ cái đầu và viết thường chữ cái sau.
- Bạn có thể tham khảo bài viết. [Code convention là gì? Các quy tắc chung khi viết code](https://vietnix.vn/code-convention-la-gi/)


#### Name Convention (Quy chuẩn đặt tên):
Trong Java khi đặt tên biến bạn cần phải tuân theo quy chuẩn đặt tên chung:
* Tên biến được chia thành các từ, ngoại trừ từ đầu tiên thì các từ tiếp theo bạn viết hoa chữ cái đầu và viết thường chữ cái sau.
* **Ví dụ:** `banKinh`, `dienTich`, `luongNhanVien`, `diemTrungBinh`,...

## 2. Chú thích trong Java (Comment)
Chú thích là giải pháp bổ sung thông tin vào code nhằm làm rõ nội dung, giải thích câu lệnh, mục đích của code... giúp người đọc dễ nắm bắt và thuận lợi bảo trì. Các chú thích sẽ không được coi là câu lệnh và sẽ bị loại bỏ khi chương trình thực thi.

* **Chú thích trên một dòng:** Dùng `//`
  ```java
  // Đây là chú thích
  // Chú thích giúp code rõ ràng hơn
  ```
* **Chú thích trên nhiều dòng:** Đặt nội dung giữa `/*` và `*/`
  ```java
  /* 
  Đây là chú thích 
  trên nhiều dòng 
  */
  ```

## 4. Toán tử

### a. Toán tử gán
* **Cú pháp:** `[Toán hạng 1] = [Toán hạng 2];`
* **Ý nghĩa:** Gán giá trị của toán hạng 2 cho toán hạng 1.

### b. Toán tử toán học
| Toán tử | Ý nghĩa | Ví dụ |
| :---: | :--- | :--- |
| `+` | Cộng 2 toán hạng | `X = Y + Z;` (Ví dụ: `X = 100 + 200; // 300`) |
| `-` | Trừ 2 toán hạng | `X = Y - Z;` (Ví dụ: `X = 200 - 100; // 100`) |
| `*` | Nhân 2 toán hạng | `X = Y * Z;` (Ví dụ: `X = 10 * 50; // 500`) |
| `/` | Chia 2 toán hạng | `X = Y / Z;` (Ví dụ: `X = 300 / 200; // 1`) |
| `%` | Chia dư 2 toán hạng | `X = Y % Z;` (Ví dụ: `X = 300 % 200; // 100`) |

> **Chú ý 1 (Phép chia):** Chia 2 số nguyên sẽ trả về phép chia nguyên (lấy phần nguyên). Nếu muốn lấy kết quả số thập phân, ít nhất một toán hạng phải là số thực và biến chứa kết quả phải ở dạng số thực.
> 
> **Chú ý 2 (Tràn số):** Nhân hoặc cộng các số nguyên `int` vượt quá giới hạn lưu trữ sẽ dẫn đến tràn số. Cần ép kiểu (`casting`) hoặc dùng hậu tố `L`:
> ```java
> int a = 1000000, b = 1000000;
> long d = (long) a * b; // Cách 1
> long e = 1L * a * b; // Cách 2
> ```

```Java
// Ví dụ
public class Main{
    public static void main(String[] args){
		int p = 1000000000;
		int l = 1000000000;
		// long res = p * l; như thế này nó sẽ ra lỗi vì nếu lấy 2 số int nhân với nhau thì nó sẽ lấy tích thằng này lưu tạm vào vùng nhớ int sau đó với gán cho thằng res nên ở đây cũng sẽ bị tràn.
		// cách làm đúng sẽ là
		long res = (long)p * l;
		System.out.println(res);
    }
}
```
> **Chú ý 3 (Thứ tự ưu tiên):** Nhân chia trước, cộng trừ sau. Các toán tử cùng mức ưu tiên thực hiện từ trái qua phải. Nên sử dụng dấu ngoặc tròn `()` để biểu thức thực thi đúng ý muốn.

### c. Toán tử so sánh
Trả về kết quả đúng (`true`) hoặc sai (`false`).

| Toán tử | Ý nghĩa | Ví dụ |
| :---: | :--- | :--- |
| `>` | Lớn hơn | `10 > 50` $\rightarrow$ `false` |
| `>=` | Lớn hơn hoặc bằng | `20 >= 10` $\rightarrow$ `true` |
| `<` | Nhỏ hơn | `10 < 50` $\rightarrow$ `true` |
| `<=` | Nhỏ hơn hoặc bằng | `20 <= 20` $\rightarrow$ `true` |
| `!=` | Khác | `10 != 20` $\rightarrow$ `true` |
| `==` | Bằng | `10 == 10` $\rightarrow$ `true` |

---

### d. Toán tử logic
Kết hợp nhiều phép so sánh bằng các cổng logic: `AND`, `OR`, `NOT`.

| Toán tử | Ký hiệu | Ví dụ |
| :---: | :---: | :--- |
| AND | `&&` | `(x >= 10) && (x <= 50)` |
| OR | `\|\|` | `(a >= 10) \|\| (a % 2 == 0)` |
| NOT | `!` | `!(a <= 10)` |

* **Bảng chân lý AND (`&&`):** Chỉ đúng khi **mọi** mệnh đề thành phần đều đúng.
* **Bảng chân lý OR (`||`):** Chỉ sai khi **mọi** mệnh đề thành phần đều sai (đúng khi có ít nhất 1 mệnh đề đúng).
* **Bảng chân lý NOT (`!`):** Đảo ngược giá trị chân lý (`0` $\rightarrow$ `1`, `1` $\rightarrow$ `0`).

## 6. Cấu trúc rẽ nhánh

### a. Câu lệnh `if`
Thực thi 1 nhóm câu lệnh khi một điều kiện thỏa mãn.
```java
if (condition) {
    // Các câu lệnh khi condition đúng
}
```

### b. Câu lệnh `if - else`
Thực thi khối lệnh này khi đúng, và khối lệnh khác khi sai.
```java
if (condition) {
    // Code khi condition đúng
} else {
    // Code khi condition sai
}
```

### c. Cấu trúc `if - else if - else`
Kiểm tra nhiều điều kiện khác nhau tuần tự:
```java
if (condition1) {
    // Code nếu condition1 đúng
} else if (condition2) {
    // Code nếu condition1 sai và condition2 đúng
} else if (conditionN) {
    // Code nếu N-1 điều kiện trước sai và conditionN đúng
} else {
    // Code nếu tất cả N điều kiện trên đều sai
}
```
> **Chú ý:** Khi một điều kiện trong chuỗi đúng, khối lệnh của nhánh đó thực thi và toàn bộ cấu trúc `if-else if` sẽ kết thúc ngay lập tức.
```java
public class Main{
    public static void main(String[] args){
     if(n>=10){
            if(n<=20){
                System.out.println("YES")
            }
            else System.out.println("NO")
        }
        else System.out.println("NO")
    }
}
```
### d. Cấu trúc `switch - case`
Kiểm tra một giá trị `val` với nhiều trường hợp (`case`), nếu khớp trường hợp nào thì thực thi code trong `case` đó. Nếu không khớp bất kỳ `case` nào thì chạy `default`.
```java
switch (val) {
    case 1:
        // code
        break;
    case 2:
        // code
        break;
    default:
        // code
}
```
*(Mỗi khối case nên kết thúc bằng từ khóa `break`).*

## 6. Bảng mã ASCII và xử lý ký tự

Bảng mã gồm 256 ký tự, mỗi ký tự ứng với một mã số (mã ASCII).

### Các dải mã ASCII quan trọng:
* `A - Z`: $65 - 90$
* `a - z`: $97 - 122$
* `0 - 9`: $48 - 57$

> **QUAN TRỌNG:** Kiểu `char` trong Java có thể thực hiện các phép toán cộng, trừ, nhân, chia như số nguyên dựa trên mã ASCII của nó.

### Một số câu lệnh kiểm tra ký tự cơ bản:
```java
char c = 'a';

// Kiểm tra ký tự in thường
if (c >= 97 && c <= 122) { ... }
if (c >= 'a' && c <= 'z') { ... }

// Kiểm tra ký tự in hoa
if (c >= 65 && c <= 90) { ... }
if (c >= 'A' && c <= 'Z') { ... }

// Kiểm tra chữ số
if (c >= 48 && c <= 57) { ... }
if (c >= '0' && c <= '9') { ... }

// bảng mã ascii

        System.out.println(kiTu+3); // nó sẽ chuyển sang mã ascii để cộng với 3
        System.out.println((char)65); 
        kiTu = 'a';
